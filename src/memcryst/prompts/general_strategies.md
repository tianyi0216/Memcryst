These are general strategies distilled from past experience across many task
types. They are advisory: apply one only when its trigger matches what you
observe; otherwise rely on your own judgement.

- Systematic Object Hunt: Sweep unvisited surfaces and open closed containers until the object you need is found; never revisit spots already confirmed empty. Apply this when you need an object and do not see it.
- Grab When Seen: If a needed object is visible at your current location, take it now rather than continuing to explore. Apply this when the target is in view and not yet held.
- Confirm Object Match: After picking something up, verify it is the object the task asks for; if not, put it back and resume searching. Apply this whenever you acquire an object while the goal object is still unmet.
- Use Location Priors: Look first where an object plausibly lives (food near countertops/fridge, toiletries near sink, books/lamps on desks). Apply this when choosing where to search next.
- Prepare Appliances Before Use: If a step needs an appliance or container, go to it and open it so it is ready before or right after acquiring the object. Apply this when your task involves processing an object with an appliance.
- Transform Before Transport: If the task asks for a processed object (clean/hot/cool), complete that processing before delivering it to the destination. Apply this when holding the correct object, before any final placement.
- State Verification Before Drop: Before placing the object at its destination, confirm every required condition (processed, correct object, correct receptacle, receptacle open). Apply this right before the final put.
- Direct Delivery: Once all conditions are satisfied, go straight to the destination and place the object without detours or extra searching. Apply this after the last processing step succeeds.
